## Dashboard interativo no Google Colab

Abra [`dashboard_co2_colab.ipynb`](./dashboard_co2_colab.ipynb) no Colab e execute as células em ordem. O notebook usa controles `ipywidgets` e gráficos Plotly, sem iniciar um servidor Streamlit. O tema azul-marinho, incluindo o quadro em volta dos gráficos, está em [`tema_co2.py`](./tema_co2.py) e é aplicado automaticamente. O notebook usa `doc/owid-co2-data.csv` quando disponível e, caso contrário, carrega os dados diretamente da Our World in Data.
